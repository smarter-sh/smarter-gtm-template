# ADR-004: The Embed Script Is Loaded from jsDelivr, at a Pinned Version

## Status

Accepted

## Context

The embed script is published to npm, so jsDelivr serves every version of it, with its `embed/` files beside it. A tag that loads a moving version (`@0`) changes on every site without anyone publishing the container again.

## Decision

The template's **Embed script version** field (advanced) defaults to the exact version that this template is tested with, `0.9.0`, which a release of the template updates, and accepts an exact version, or a range like `0.9`, which a GTM user can choose deliberately. A regular expression validates it, and the template url-encodes it into `https://cdn.jsdelivr.net/npm/@smarter.sh/ui-chat@<version>/dist/embed.js`.

## Consequences

- **Positive:**
  - What runs is what was tested, unless the GTM user chooses otherwise.
- **Negative:**
  - A fix in the embed script reaches sites when they update the template in their container, which the Gallery prompts them to do.
